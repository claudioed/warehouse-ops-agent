# Security Policy

## Supported Versions

Security fixes are applied to the latest code on the `develop` branch and to
the latest published release. Older releases are not actively supported.

## Reporting a Vulnerability

Please **do not** open a public issue for a suspected vulnerability.

Report it privately through [GitHub Private Vulnerability
Reporting](https://github.com/claudioed/warehouse-ops-agent/security/advisories/new).
Include a clear description, reproduction steps or proof of concept, affected
versions or commit SHA, and the potential impact.

We will acknowledge receipt within 7 days, investigate the report, and keep
you informed about remediation and coordinated disclosure. Please do not
publicly disclose the vulnerability until a fix and disclosure timeline have
been agreed.
